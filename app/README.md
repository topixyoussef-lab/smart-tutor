# المُدرِّس الذكي (Smart Tutor)

نظام دراسة بالذكاء الاصطناعي يعمل في المتصفح: ارفع أي كتاب (PDF خفب لاي مادة)، والنظام يشرح لك المنهج، يعمل امتحانات بالمستويات اللي تختارها، يصححها لك، ويحلّل نقاط ضعفك.

## المميزات

- **رفع كتاب PDF** واستخراج النص تلقائياً وكشف الفصول (من العناوين أو الفهرس).
- **شرح مفصّل** لكل فصل بثاً مباشراً (streaming) بالعربية، مع القوانين والأمثلة المحلولة.
- **أسئلة متابعة** (شات) داخل الفصل — الـ AI يجاوب بناءً على نص الكتاب فقط.
- **ملخص سريع** لكل فصل (نوتات مراجعة).
- **توليد امتحانات**: اختر الفصول، المستوى (سهل/متوسط/صعب)، أنواع الأسئلة (اختيار من متعدد، مفهومي، مسائل)، وعدد الأسئلة.
- **تصحيح تلقائي**: الاختياري يُصحح فوراً، والمقالي يصححه الـ AI بلا معايير، مع درجة نهائية.
- **شرح لكل سؤال** بعد التصحيح (صح/غلط، لماذا، الحل النموذجي).
- **تحليل نقاط الضعف** + خطة مراجعة + تراكم نقاط الضعف عبر كل الامتحانات.

## المتطلبات

- Node.js **18 فأحدث** (اختُبر على 24).
- اتصال إنترنت (للـ AI والمكتبات الخارجية في الواجهة).
- مفتاح API مجاني من [OpenRouter](https://openrouter.ai) (الموديلات المنتهية بـ `:free` مجانية 100%).

## التشغيل

```bash
cd app
npm install
npm start
```

ثم افتح: **http://localhost:3000**

أو من Windows اكليك مزدوج على `start.bat` (يثبّت ويشغّل).

## الاستخدام

1. **إعدادات ← مزوّد/مفتاح API**: اختر OpenRouter والأمّل مفتاحك (أو اتركه كما هو إذا وضعته في `.env`). المفاتيح محفوظة محلياً فقط.
2. **المكتبة**: ارفع أي كتاب PDF (فيزياء، رياضيات، كيمياء، أحياء، تاريخ، لغة...) — سيظهر الكتاب مع فصوله. عدّل الفصول يدوياً إذا لزم.
3. **الشرح**: اختر الكتاب والفصل → "اشرح لي" أو "ملخص"، واكتب أسئلتك في الشات بالأسفل.
4. **الامتحانات**: حدد الفصول والمستوى والأنواع والعدد → "توليد الامتحان" → ابدأ → سلم.
5. **النتائج**: الدرجة، شرح كل سؤال، نقاط الضعف، وخطة المراجعة. شريط "نقاط الضعف" يتراكم عبر الامتحانات.

## الإعدادات الاختيارية (ذكية ومجانية)

- **OpenRouter** (موصى به): موديلات مجانية مختارة مسبقاً مثل `minimax/m3` و `GLM 5.2` و `Nemotron Super`. اكتب أي موديل مخصص في خانة «موديل مخصص».
- **Moonshot (Kimi)**: مدعوم في التطبيق، لكنه يحتاج رصيداً في حساب Moonshot (يملك المفتاح الذي دخلت به لم يكن له رصيد).

> **مهم:** قائمة الموديلات المجانية تتغير من وقت لآخر. لو الموديل لم يعد متاحاً، اختر غيره من الإعدادات.

## المخطط والتخزين

```
app/
  server.js          خادم Express + كل واجهات API
  src/pdf.js         استخراج نص PDF + كشف الفصول
  src/ai.js          عميل OpenRouter/Moonshot + بث
  src/prompts.js     قوالب أوامر الشرح/الامتحان/التصحيح/التحليل
  src/store.js       تخزين JSON محلي
  public/            الواجهة (HTML/CSS/JS)
  data/              بيانات المستخدم (كُتب، امتحانات، نتائج، إعدادات) — لا تُرفع
  scripts/           أدوات اختبار وتوليد كتاب تجريبي
```

## الأمان

- مفاتيح API تُحفظ في `.env` (مستثنى من GitHub) و `data/_settings.json` (غير مرفوع في git).
- لا ترسل مفاتيحك في أي رسالة مفتوحة؛ وإن أرسلتها سابقاً يُفضّل توليد مفتاح جديد من لوحة OpenRouter.

## ملاحظات

- الكتب الممسوحة ضوئياً (بدون نص) ستعطي استخراجاً محدوداً؛ الأمر يحتاج OCR.
- الموديلات المجانية قد تكون أبطأ بسبب حصة الاستخدام — جرّب موديلاً آخر إذا لزم.
- المتصفحات الحديثة فقط (Chrome/Edge/Firefox)، والواجهة مبنية على Tailwind عبر CDN.ت
